# Google Sign-In Fix After Package Name Change

## Problem
Google Sign-In is failing after changing the package name from `com.finflow.app` to `com.finflowai.money.manager`.

## Root Cause
When you change the Android package name, you must update the SHA-1 certificate fingerprints in Firebase Console for Google Sign-In to work correctly.

## Solution

### Step 1: Get SHA-1 Fingerprints

#### For Debug Build (Development)
The debug keystore is automatically generated by Android. The debug SHA-1 fingerprint for your system is:

**Debug SHA-1 Fingerprint:**
```
33:62:01:78:7A:05:68:F7:C6:01:F6:B2:C0:FB:BE:4A:0F:18:3F:EB
```

You can also generate it manually with:
```bash
keytool -list -v -keystore "%USERPROFILE%\.android\debug.keystore" -alias androiddebugkey -storepass android -keypass android
```

#### For Release Build (Production)
Use the existing release keystore (already found):

```bash
keytool -list -v -keystore "android\finflow_secure.keystore" -alias finflow_secure_key -storepass "SecureFinFlow2025!" -keypass "SecureFinFlow2025!"
```

**Release SHA-1 Fingerprint:**
```
A0:6C:29:C6:94:F0:13:49:65:6E:EF:F9:41:5B:8F:58:D2:4A:25:9C
```

### Step 2: Update Firebase Console

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Select your project: `finflow-a7bc8`
3. Go to **Project Settings** (⚙️ icon)
4. Click on the **General** tab
5. Scroll down to **Your apps** section
6. Find your Android app with package name `com.finflowai.money.manager`
7. Click **Add fingerprint**
8. Add the SHA-1 fingerprint(s):

**For Development (Debug):**
- Add the SHA-1 from your debug keystore

**For Production (Release):**
- Add: `A0:6C:29:C6:94:F0:13:49:65:6E:EF:F9:41:5B:8F:58:D2:4A:25:9C`

### Step 3: Verify Google Sign-In is Enabled

1. In Firebase Console, go to **Authentication** section
2. Click on the **Sign-in method** tab
3. Ensure **Google** is enabled
4. Verify the **Authorized domains** include your app domains

### Step 4: Update google-services.json

After adding the fingerprints, download the updated `google-services.json` file from Firebase Console and replace the existing one in your project:

1. In Firebase Console, go to **Project Settings**
2. Find your Android app
3. Click **Download google-services.json**
4. Replace the existing file at: `android/app/google-services.json`

### Step 5: Rebuild the App

```bash
flutter clean
flutter pub get
flutter build apk --debug
```

### Step 6: Test Google Sign-In

1. Install the rebuilt APK on your device/emulator
2. Try Google Sign-In again

## Additional Troubleshooting

### If Google Sign-In still fails:

1. **Check Package Name**: Ensure the package name in `android/app/build.gradle.kts` matches exactly what's in Firebase Console

2. **Check SHA-1**: Verify you added the correct SHA-1 fingerprints for both debug and release builds

3. **Check App Registration**: Ensure your app is properly registered in Firebase Console with the new package name

4. **Clear App Data**: On your device, clear the app data and cache, then try again

5. **Check Console Logs**: Look for any error messages in the Flutter debug console

### Common Error Messages and Solutions:

- **"INVALID_CERT_HASH"**: SHA-1 fingerprint not added or incorrect
- **"DEVELOPER_ERROR"**: Package name mismatch or app not properly configured
- **"SIGN_IN_FAILED"**: Google Sign-In not enabled in Firebase or configuration issues

## Quick Verification

To verify your setup is correct:

1. Check that `google-services.json` contains the correct package name: `"package_name": "com.finflowai.money.manager"`
2. Verify SHA-1 fingerprints are added in Firebase Console
3. Ensure Google Sign-In is enabled in Authentication settings
4. Rebuild and test the app

## Notes

- Debug and release builds use different keystores, so you need both fingerprints
- The debug keystore is user-specific, so each developer may need to add their own debug SHA-1
- The release keystore fingerprint is shared and should be added once for the team
